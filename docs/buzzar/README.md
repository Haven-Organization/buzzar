# Buzzar planning docs

Buzzar is a fork of [Third Room](https://github.com/matrix-org/thirdroom) (upstream remote: `upstream`,
base commit `01bc731b`, 2023-07-11). It aims for VRChat feature parity while staying a Matrix client.

- [parity-checklist.md](parity-checklist.md): the gap checklist and phase order. **Start here.**
- [reference-worlds.md](reference-worlds.md): known-good MSC3815 worlds + portal format (compat fixtures).
- [research/thirdroom-inventory.md](research/thirdroom-inventory.md): what the codebase has today, with file refs.
- [research/vrchat-features.md](research/vrchat-features.md): VRChat creator-docs feature inventory and limits.
- [research/matrix-research.md](research/matrix-research.md): MSC3815, MatrixRTC/LiveKit, SDK choice, script security.

The research files were written by AI research agents on 2026-11-13. They have only been partly
spot-checked against the code. Re-verify numbers before relying on them.
